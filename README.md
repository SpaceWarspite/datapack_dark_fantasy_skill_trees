# Dark Fantasy Skill Trees

Контентный мод-аддон для **Passive Skill Tree** под **Minecraft 1.21.1 / NeoForge**.

Мод добавляет дополнительные тематические деревья прокачки в стиле Dark Fantasy и распространяет игровые данные и клиентские ресурсы в одном `.jar`-файле.

Текущая версия: **0.2.13**

## Что добавляет мод

Доступны четыре дерева:

- **Warrior** — дерево боевой специализации;
- **Mage** — дерево магической специализации с интеграцией Iron's Spells 'n Spellbooks.
- **Miner** — спираль добычи с бонусами к скорости, рудному опыту и сохранению прочности.
- **Mining Quests** — независимые задания за добычу блоков с разовыми наградами очков навыков.

Текущая версия содержит:

- 61 узел Warrior;
- 115 узлов Mage;
- 244 узла навыков всего;
- 36 узлов Miner и 32 задания добычи;
- собственные связи и геометрию деревьев;
- requirements для части навыков;
- специализации и ограничения выбора через `tags` / `skillLimitations`;
- русскую и английскую локализацию;
- собственные иконки выбора деревьев.

Хрономант содержит 21 узел и три конечных кейстоуна. Его основная часть содержит 15 узлов. После семи узлов ствола она расходится на два рукава по четыре узла с кейстоунами «Хрономант» и «Властелин времени». Оба рукава можно изучить совместно. Полная ветка даёт суммарно +119% к атрибуту сокращения каста, +133% к атрибуту сокращения перезарядки, +21% к движению при касте, +14% к сопротивлению заклинаниям и −105 маны. Это ровно семь прежних сумм модификаторов. Фактическое время каста и перезарядки зависит от формулы Iron's Spells.

От «Потока сознания» также выходит третий рукав из шести навыков. Он даёт +25%, +25%, +50%, +50%, +50% и +50% длительности собственных положительных эффектов, наложенных на себя при касте. Всего +250%, то есть длительность ×3,5. Конечный кейстоун «Вечный миг» дополнительно отнимает 50 маны. Зелья, эффекты союзников, отрицательные и бесконечные эффекты не продлеваются. Существующие эффекты не пересчитываются при покупке навыка. Поддержаны наложения внутри onCast, включая «Ангельские крылья». Отложенные наложения вне вызова onCast не продлеваются. Всего Хрономант содержит 21 узел и три кейстоуна.

Контент ветки воспроизводится командой `python tools/generate_chronomancer_content.py` и проверяется командой `python tools/validate_chronomancer.py`. Проверка установленного JAR доступна через `--jar`, сравнение с прежним модом через `--baseline-jar`. Геометрическая проверка сохраняет исходный тесный вход из двух узлов и требует зазор от 8 единиц для остальной ветки.

Дерево Miner состоит из шести групп по шесть узлов. Порядок ID: `06`, `01–05`, `12`, `07–11`, `18`, `13–17`, `24`, `19–23`, `30`, `25–29`, `36`, `31–35`. `miner_06` — начальный узел и первые контрольные ворота; для них нужно хотя бы раз создать зачарованный стол. Остальные ворота требуют создать якорь возрождения, проводник, калиброванный датчик скалка, маяк и шалкеровый ящик. ID и индивидуальные бонусы навыков сохранены.

Каждая группа даёт суммарно +50% скорости добычи и опыта с руды. Бонусы скорости по ID составляют +5%, +5%, +5%, +10%, +10% и +15%; двенадцать узлов дают по +25% опыта с руды. Двадцать узлов также дают по 5% сохранения прочности инструментов и брони.

Mining Quests содержит четыре накопительных этапа для камня, угля, железа, золота, редстоуна, алмазов, обсидиана и древних обломков. Обычные и глубинные руды суммируются. Золото также учитывает незерскую золотую руду. Уже накопленная ванильная статистика учитывается. Каждый этап можно получить только один раз, даже если сбросить дерево навыков.

Изучение каждого задания стоит 1 очко навыка и начисляет указанную награду плюс это очко. Чистый прирост за 32 задания составляет 203 очка, всего начисляется 235. Для игры со всеми деревьями установите лимит очков Passive Skill Tree на 500. Текущая игровая конфигурация уже использует 500. Лимит относится к настройкам игры и не входит в JAR мода.

## Как это работает

Мод использует JSON-контент Passive Skill Tree. Java-код отслеживает статистику добычи, доступность Элдритча и длительность собственных заклинаний.

Passive Skill Tree остаётся движком деревьев навыков. Мод поставляет ему JSON-данные и клиентские ресурсы, а Java-мост читает ванильную статистику блоков и открывает достигнутые задания. Учитывается и статистика, накопленная до установки мода.

В одном JAR находятся одновременно:

```text
data/darkfantasy/
├── advancement/
├── function/
├── skill_trees/
├── skills/
└── mining_quests/

assets/darkfantasy/
├── lang/
└── textures/
```

`data/` используется как datapack-часть мода, а `assets/` — как resource-pack-часть.

Отдельная установка datapack, resource pack или Moonlight Global Datapacks больше не требуется.

## Зависимости

Обязательные:

- Minecraft **1.21.1**
- NeoForge
- Passive Skill Tree (`skilltree`)
- Iron's Spells 'n Spellbooks (`irons_spellbooks`)

Первая рабочая версия проверена в сборке с:

- NeoForge **21.1.250 или новее**
- Passive Skill Tree **1.21.1-1.0.0**
- Iron's Spells 'n Spellbooks **1.21.1-3.16.3**

## Установка

1. Убедиться, что установлены обязательные зависимости.
2. Скопировать:

```text
darkfantasyskilltrees-<version>.jar
```

в папку:

```text
.minecraft/mods/
```

3. Запустить Minecraft. Для дерева Mage также требуется Iron's Spells 'n Spellbooks.

Старые версии проекта в виде отдельного datapack в `moonlight-global-datapacks` и отдельного resource pack использовать одновременно с JAR не нужно.

## Требования для сборки

Нужен **JDK 21**.

Проверка Java:

```powershell
java -version
```

Ожидается Java 21, например:

```text
openjdk version "21..."
```

Все команды ниже выполняются из корневой папки проекта, где находится `gradlew.bat`.

## Сборка

Обычная сборка:

```powershell
.\gradlew.bat build
```

После успешной сборки Gradle выведет:

```text
BUILD SUCCESSFUL
```

Готовый JAR появляется в:

```text
build\libs\
```

Например:

```text
build\libs\darkfantasyskilltrees-0.2.13.jar
```

## Удаление ранее собранного JAR

Удалить все собранные версии Dark Fantasy Skill Trees из `build\libs`:

```powershell
Remove-Item .\build\libs\darkfantasyskilltrees-*.jar -Force
```

Если Windows сообщает, что файл используется другим процессом, необходимо сначала закрыть процесс, удерживающий JAR. Чаще всего это Minecraft/Java или программа, открывшая файл.

## Чистая пересборка

Рекомендуемый вариант, если нужно удалить старые build-артефакты и собрать проект заново:

```powershell
.\gradlew.bat clean build
```

Это обычно удобнее, чем вручную удалять старый JAR.

## Версия мода

Версия задаётся в:

```text
gradle.properties
```

параметром:

```properties
mod_version=0.2.13
```

После изменения версии и новой сборки имя JAR обновится автоматически, например:

```text
darkfantasyskilltrees-0.2.13.jar
```

## Namespace и Mod ID

Mod ID:

```text

```


Это разные идентификаторы и менять namespace без необходимости не следует, поскольку на него уже ссылаются ID деревьев и навыков:

## Проверка длительности собственных заклинаний

`./gradlew.bat verifySpellDuration` проверяет расчёт длительности и контекст каста. Эта проверка также входит в обычную сборку.

Проверки контента без дополнительных Python-библиотек:

```powershell
python tools/validate_chronomancer.py
python tools/validate_mining_content.py
```

Сравнение подветки длительности с предыдущим JAR:

```powershell
python tools/validate_duration_branch.py --baseline-jar <предыдущая-сборка.jar> --chrono-only
```

Флаг `--chrono-only` ограничивает сравнение Хрономантом и допускает отдельные изменения баланса других веток. Без флага сравниваются определения всех прежних навыков.

GameTest расположен в `src/durationSmoke` и не включается в основной JAR. Для изолированного теста нужны копии установленных skilltree, irons_spellbooks, irons_lib, geckolib, curios и player-animation-lib в отдельной папке. Запуск: `./gradlew.bat runGameTestServer -PdurationSmokeMods=<папка-с-копиями-модов>`. Тестовый сервер использует отдельный каталог `.audit/duration-smoke-run`.

## Баланс релиза 0.2.13

Баффы и дебаффы двенадцати веток Mage вне Хрономанта умножены на 3,5 относительно исходных значений. Изменены 92 навыка, 146 положительных модификаторов и 9 штрафов. Все 21 узел Хрономанта и общий старт «Маг» сохраняют собственный баланс. Геометрия и условия открытия сохранены.

Для воспроизведения или проверки баланса нужен исходный JAR 0.2.11-experimental, до усиления остальных веток:

```powershell
python tools/scale_mage_branches.py --baseline-jar <0.2.11-experimental.jar> --factor 3.5
python tools/scale_mage_branches.py --baseline-jar <0.2.11-experimental.jar> --factor 3.5 --check
python tools/scale_mage_branches.py --baseline-jar <0.2.11-experimental.jar> --factor 3.5 --check --jar build/libs/darkfantasyskilltrees-0.2.13.jar
```

Повторный запуск не умножает уже усиленные значения. Флаг `--replace-factor 6` позволяет заменить предыдущий баланс ×6 на ×3,5.

Полное описание изменений находится в [заметках к релизу 0.2.13](docs/releases/0.2.13.md).
